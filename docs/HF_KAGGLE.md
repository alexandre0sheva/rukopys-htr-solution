# Hugging Face and Kaggle Publishing

## Hugging Face Dataset Upload

Authenticate:

```bash
hf auth login
hf auth whoami
```

Create and upload the curated dataset:

```bash
rukopys upload-dataset \
  --dataset-dir data/curated/rukopys_mvp \
  --repo-id AlexandreSheva/rukopys-curated-mvp \
  --private
```

The curated folder includes a Hub-compatible `README.md` dataset card generated by the curator.

For larger uploads, prefer the resumable CLI uploader:

```bash
hf upload-large-folder \
  AlexandreSheva/rukopys-curated-mvp \
  data/curated/rukopys_mvp \
  --type dataset
```

## Hugging Face Model Upload

Upload after local training:

```bash
rukopys upload-model \
  --model-dir runs/vlm_page_json_qlora \
  --repo-id AlexandreSheva/rukopys-page-vlm-qlora \
  --private
```

Or push from the training command:

```bash
rukopys train-vlm-qlora \
  --train-jsonl data/curated/rukopys_mvp/page_sft.jsonl \
  --base-model Qwen/Qwen2.5-VL-3B-Instruct \
  --output-dir runs/vlm_page_json_qlora \
  --push-to-hub \
  --hub-model-id AlexandreSheva/rukopys-page-vlm-qlora
```

The training output is a PEFT/LoRA adapter folder plus processor files. Inference can load that adapter folder directly.

git status

Keep these out of Git:

- `data/`
- `runs/`
- `outputs/`
- `.venv/`
- `~/.kaggle/kaggle.json`
- Hugging Face tokens

## Kaggle Submission

Install:

```bash
pip install -e ".[kaggle]"
```

Credentials:

```bash
mkdir -p ~/.kaggle
# place kaggle.json in ~/.kaggle/kaggle.json
chmod 600 ~/.kaggle/kaggle.json
```

Build a submission:

```bash
rukopys make-submission \
  --predictions outputs/page_predictions.jsonl \
  --sample-submission data/raw/rukopys/sample_submission.csv \
  --output outputs/submission.csv
```

Submit:

```bash
rukopys submit-kaggle \
  --submission outputs/submission.csv \
  --message "page-vlm qlora mvp"
```

Check status with the Kaggle CLI:

```bash
kaggle competitions submissions -c handwritten-to-data
```

You can also upload `outputs/submission.csv` manually on the Kaggle competition submit page.
